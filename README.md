# Kamapra Portfolio

Website portofolio pribadi **I Kadek Mario Prayoga**, yang dirancang untuk mendokumentasikan perjalanan belajar, proyek, dan keahlian dalam pengembangan web. Dibangun menggunakan teknologi web modern untuk performa tinggi dan pengalaman pengguna yang menarik.

![Kamapra Preview](/public/Kamapra.png)

## 🚀 Fitur Utama

- **Desain Modern & Responsif**: Dibangun dengan **Tailwind CSS 4** untuk tampilan yang bersih dan adaptif di semua perangkat.
- **Performa Tinggi**: Menggunakan **Next.js 16 (App Router)** dan **React 19**.
- **Animasi Interaktif**: Integrasi **GSAP** untuk animasi halus dan efek **Snowfall** untuk estetika visual.
- **AI Chatbot**: Dukungan chat cerdas menggunakan integrasi **Chatbase**.
- **SEO Optimized**: Metadata dinamis dan struktur semantik untuk visibilitas mesin pencari yang optimal.
- **Analytics**: Pemantauan trafik real-time dengan **Vercel Analytics**.

## 🛠️ Stack Teknologi

- **Framework**: [Next.js 16](https://nextjs.org/)
- **Bahasa**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Komponen**: React Icons, React Intersection Observer
- **Animasi**: GSAP, React Snowfall
- **Deployment**: Vercel

## 📦 Cara Menjalankan

Ikuti langkah-langkah ini untuk menjalankan proyek di lokal komputer Anda:

1.  **Clone repositori:**

    ```bash
    git clone https://github.com/username/kamapra.git
    cd kamapra
    ```

2.  **Instal dependensi:**

    ```bash
    npm install
    # atau
    pnpm install
    ```

3.  **Jalankan server development:**

    ```bash
    npm run dev
    ```

4.  Buka [http://localhost:3000](http://localhost:3000) di browser Anda untuk melihat hasilnya.
