## Overview

Setiap developer pasti punya satu proyek yang menjadi titik awal, dan proyek ini adalah salah satunya buat saya. Ini pertama kalinya saya memakai framework, dan juga pertama kalinya saya men-deploy sebuah website sampai bisa dibuka lewat tautan publik, walaupun masih lewat Vercel yang serba dimudahkan.

Project UTS ini berupa landing page restoran kuliner bernama "Foo die" yang dibangun dengan Next.js dan Tailwind CSS. Halamannya menampilkan hero section, menu hidangan pilihan, ulasan pelanggan, dan newsletter, semuanya dengan layout yang responsif.

## Latar Belakang

Proyek ini adalah tugas UTS mata kuliah Pemrograman Web. Tugasnya membuat sebuah website yang mencerminkan apa yang sudah dipelajari di kelas, dan saya memilih tema restoran kuliner karena strukturnya jelas, visualnya menarik, dan banyak komponen yang bisa dipelajari, mulai dari bagian pembuka, daftar menu, sampai testimoni.

Sebelum proyek ini, saya terbiasa membuat halaman web dasar. Di sini saya memutuskan untuk mencoba hal baru: memakai Next.js sebagai framework dan Tailwind CSS untuk styling. Keputusan itu terasa seperti lompatan, tetapi justru itu yang membuat proyek ini berkesan.

## Tujuan

- Menyelesaikan proyek UTS Pemrograman Web dengan hasil yang utuh
- Belajar memakai framework untuk pertama kalinya, yaitu Next.js
- Mencoba Tailwind CSS dan pendekatan utility-first
- Membuat landing page dengan layout responsif yang nyaman di berbagai ukuran layar
- Belajar men-deploy website sampai bisa diakses secara publik

## Peran Saya

Saya mengerjakan seluruh bagian website ini, mulai dari menyusun struktur halaman, membangun komponen dengan Next.js dan TypeScript, mengatur tampilan dengan Tailwind CSS, sampai men-deploy-nya ke Vercel.

## Fitur Utama

### Hero section

Bagian pembuka yang menjadi kesan pertama pengunjung. Di sini ditampilkan identitas "Foo die" dengan tampilan yang menarik perhatian dan mengajak pengunjung menjelajah lebih jauh.

### Menu hidangan pilihan

Daftar hidangan pilihan ditampilkan dalam tata letak yang rapi, sehingga pengunjung bisa langsung melihat apa saja yang ditawarkan restoran.

### Ulasan pelanggan

Testimoni pelanggan membantu membangun rasa percaya. Untuk bisnis kuliner, pendapat orang lain sering menjadi pertimbangan sebelum seseorang memutuskan mencoba.

### Newsletter

Bagian newsletter memungkinkan pengunjung berlangganan informasi terbaru, seperti menu baru atau promo.

### Layout responsif

Seluruh halaman dirancang responsif agar tetap nyaman dilihat di ponsel, tablet, maupun desktop.

## Proses Desain

Saya memulai dengan membayangkan alur seorang pengunjung restoran online: pertama tertarik dengan tampilannya, lalu ingin melihat menu, lalu mencari alasan untuk percaya, dan terakhir ingin tetap terhubung. Susunan halaman saya buat mengikuti alur itu, dari hero section, menu, ulasan, hingga newsletter.

Tampilan dibuat bersih dan menggugah selera, dengan memperhatikan hierarki judul, ruang kosong, dan penataan gambar agar halaman terasa menarik tanpa terlalu ramai.

## Pengembangan

### Pertama kali memakai framework

Next.js adalah framework pertama yang saya pakai. Ada banyak konsep baru, seperti pembagian komponen dan struktur proyek yang berbeda dari menulis halaman biasa. Di awal terasa asing, tetapi setelah terbiasa, cara kerja ini membuat kode jauh lebih rapi dan mudah dirawat karena setiap bagian halaman bisa dipisah menjadi komponen sendiri.

### Tailwind CSS

Tailwind CSS adalah pengalaman baru lainnya. Pendekatan utility-first membuat saya bisa menyusun tampilan langsung di dalam komponen tanpa bolak-balik ke file CSS terpisah, dan membuat penyesuaian untuk layar berbeda jadi lebih praktis.

### TypeScript

TypeScript membantu menjaga kode lebih terstruktur dan mengurangi kesalahan kecil sejak awal, terutama saat data seperti daftar menu dan ulasan dipakai berulang di beberapa komponen.

### Deploy pertama ke Vercel

Bagian yang paling bikin senang adalah ketika website akhirnya bisa dibuka lewat tautan publik. Walaupun proses deploy-nya dimudahkan oleh Vercel, ini pertama kalinya saya melihat hasil kerja saya bisa diakses siapa saja, bukan hanya di komputer sendiri. Kode proyek tersedia di GitHub.

## Tantangan dan Pelajaran

Tantangan terbesar proyek ini adalah beradaptasi dengan hal-hal baru sekaligus, yaitu framework, utility-first styling, dan TypeScript, dalam satu tugas. Banyak waktu terpakai untuk memahami cara kerjanya sebelum benar-benar bisa menghasilkan tampilan yang diinginkan.

Dari proyek ini saya belajar beberapa hal:

- Memakai framework butuh waktu untuk terbiasa, tetapi hasilnya membuat pengembangan lebih terstruktur
- Memecah halaman menjadi komponen membuat kode lebih rapi dan bisa dipakai ulang
- Tailwind CSS mempercepat proses styling dan membuat tampilan lebih konsisten
- Men-deploy website mengubah cara pandang: karya kita bukan lagi sekadar file di komputer
- Proyek kuliah bisa menjadi tempat yang aman untuk mencoba teknologi baru

## Hasil

Landing page "Foo die" berhasil diselesaikan sebagai proyek UTS Pemrograman Web dan bisa diakses di https://mario-njz.vercel.app/. Halaman ini memuat hero section, menu hidangan pilihan, ulasan pelanggan, dan newsletter dengan layout responsif. Kode sumbernya dapat dilihat di https://github.com/Kamapra18/mario.

Bagi saya, proyek ini adalah titik awal perjalanan dengan Next.js dan Tailwind CSS, dua teknologi yang kini menjadi andalan saya dalam membangun website.
